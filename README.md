Project name :(বাজার দর / BazarDor)

Description: BazarDor is a web-based market price tracking application that helps users explore daily prices of essential products in Bangladesh. Users can browse product categories, compare today's prices with previous prices, and view market-wise price information to make informed purchasing decisions.

Technology Used:

1. Next.js
2. Better Auth
3. Tailwind
4. Mongodb
5. Log in with google and github
6. api
7. toastify
8. Vercel

Key Features:

1) Daily Price Tracking — View today's prices of essential products and compare them with previous prices.

2) Dynamic Product Categories — Browse products by categories such as rice, lentils, oil, and vegetables using API-driven data.

3) Price Comparison — See how product prices have increased or decreased compared with yesterday, last week, and last month.

4) User Authentication — Sign up, sign in, and manage user profile information securely.

5) Responsive Design — Enjoy a user-friendly experience across mobile phones, tablets, and desktop devices.
